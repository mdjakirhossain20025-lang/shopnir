# ShopNir

ShopNir — আপনার প্রয়োজন, এক ঠিকানায়

Static e-commerce starter built with:
- HTML5
- CSS3
- Vanilla JavaScript
- Supabase JavaScript CDN

No Node.js, React, Vue, npm, package.json, or build system is required.

## Setup
1. Create a Supabase project.
2. Run `supabase/schema.sql` and `supabase/rls.sql` in Supabase SQL Editor.
3. Create the Storage bucket using `supabase/storage.sql`.
4. Put your Supabase URL and anon key in `js/config.js`.
5. Open `index.html`, or use VS Code Live Server if browser security prevents local authentication.
6. Deploy the files to GitHub Pages.

Personal information remains as placeholders in `js/config.js`.
