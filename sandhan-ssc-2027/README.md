# Sandhan SSC 2027 Demo Website

এটি Sandhan-এর জন্য একটি স্ট্যাটিক ডেমো ওয়েবসাইট। মোবাইল-ফ্রেন্ডলি হোমপেজ, ২০টি MCQ/২০ মিনিটের ডেমো পরীক্ষা, ফলাফল/উত্তর পর্যালোচনা এবং কোর্স ল্যান্ডিং পেজ আছে।

## ফাইলের কাঠামো
- `index.html` — হোমপেজ
- `academic/ssc-2027-model-test/index.html` — মডেল টেস্ট
- `courses/ssc-2027/index.html` — কোর্স বিক্রির ডেমো ল্যান্ডিং পেজ
- `assets/style.css` — ডিজাইন
- `assets/config.js` — সহজে বদলানোর মতো সাইট/কোর্স সেটিং
- `robots.txt`, `sitemap.xml` — SEO-এর প্রাথমিক ফাইল

## লোকালি পরীক্ষা ও অ্যাডমিন টেস্ট মোড
1. ZIP আনজিপ করে `index.html` খুলুন। সব পেজ একই ফোল্ডার কাঠামোতে রাখুন।
2. অ্যাডমিন হিসেবে উত্তর যাচাই ও বারবার পরীক্ষা করতে এই ফাইলটি খুলুন: `academic/ssc-2027-model-test/index.html?mode=test`। ফাইলটি সরাসরি খুললে (`file://`) এই মোড চালু হবে।
3. এই টেস্ট মোডে উত্তর-কী দেখা এবং বারবার পরীক্ষা দেওয়া যাবে। এটি কেবল স্থানীয় প্রিভিউ/ডেভেলপমেন্টের জন্য।
4. প্রকাশিত ওয়েবসাইটে `?mode=test` দিয়ে অ্যাডমিন মোড চালু হবে না।

## GitHub Pages-এ ডেমো প্রকাশ
1. GitHub-এ নতুন public repository তৈরি করুন।
2. ZIP-এর সব ফাইল unzip করে repository-র root-এ upload/commit করুন।
3. Repository → Settings → Pages → Build and deployment-এ `Deploy from a branch` বেছে `main` এবং `/ (root)` সিলেক্ট করুন।
4. Save করার পর GitHub Pages-এর দেওয়া URL খুলে পরীক্ষা করুন।
5. Custom domain যুক্ত করার আগে আপনার বর্তমান `sandhan.blog` সাইটের DNS/হোস্টিং বুঝে নিন। বর্তমান সাইটের DNS পরিবর্তন করবেন না, যদি না আপনি ইচ্ছাকৃতভাবে সাইট স্থানান্তর করেন।

Cloudflare Pages-এও GitHub repository connect করে একই স্ট্যাটিক ডেমো deploy করা যায়।

## যেগুলো অবশ্যই বদলাবেন
1. `assets/config.js`-এ কোর্সের নাম, মূল্য, মেয়াদ ও আসল ভর্তি লিংক।
2. `academic/ssc-2027-model-test/index.html`-এর `questions` array-তে আপনার যাচাইকৃত বিষয়ভিত্তিক প্রশ্ন ও উত্তর।
3. কোর্স পেজের নমুনা সুবিধা, মূল্য, যোগাযোগ, পেমেন্ট ও FAQ।
4. canonical URL, `robots.txt` ও `sitemap.xml`-এ প্রকৃত প্রকাশিত URL।
5. বর্তমান ওয়েবসাইটের একাডেমিক মেনু থেকে নতুন পরীক্ষার পেজে লিংক দিন।

## গুরুত্বপূর্ণ সীমাবদ্ধতা
- এটি **ফ্রন্টএন্ড ডেমো**। ফলাফল সার্ভারে সংরক্ষণ হয় না।
- স্থানীয় অ্যাডমিন টেস্ট মোডটি আসল নিরাপদ অ্যাডমিন প্যানেল নয়; এটি শুধু লোকাল ফাইল/localhost-এ কাজ করে।
- লাইভ ওয়েবসাইটে সঠিক উত্তর গোপন রাখা, নিরাপদ অ্যাডমিন লগইন, IP/শিক্ষার্থী আইডি অনুযায়ী পরীক্ষার সুযোগ নিয়ন্ত্রণ, সার্ভার-সাইড টাইমার এবং স্থায়ী ফলাফলের জন্য Supabase Auth + Database + Edge Functions (অথবা Cloudflare Pages Functions) সংযুক্ত করতে হবে। শুধু HTML/JavaScript দিয়ে এই নিরাপত্তা নিশ্চিত করা যায় না।
- শুধু ব্রাউজার-ভিত্তিক পরীক্ষা নিরাপদ/প্রকৃত উচ্চ-ঝুঁকির পরীক্ষা হিসেবে ব্যবহার করবেন না।
- প্রশ্নগুলো কেবল নমুনা; এগুলোকে SSC ২০২৭-এর অফিসিয়াল প্রশ্ন বলে প্রচার করবেন না।
- SEO-এর জন্য canonical/sitemap-এর URL প্রকাশের পর মিলিয়ে নিন। Google-এ ইনডেক্সিং বা র‍্যাঙ্কিং নিশ্চিত নয়।
